# post-quantum-cryptography

This repository contains the code I wrote as part of the implementations done as part of my study for my seminar topic 'The Quantum Threat to Modern Cryptography: The Rise of Post-Quantum Cryptography'. 
As part of the project, I studied about RSA-algorithm, Shor's Algorithm and ML-KEM algorithm, and explored their python based implementation. This is a basic study of the topics and exploration of the above mentioned algorithms. There was no new addition on my part for the project.
